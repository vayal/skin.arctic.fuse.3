# Phase template

Use this structure for every `phase-*.md` file.

## Header

- `# Phase N — Name`
- `**Parent:** [ROADMAP_MASTER.md](../ROADMAP_MASTER.md)`
- `**Template:** [PHASE_TEMPLATE.md](./PHASE_TEMPLATE.md)`

## Phase metadata

| Field | Value |
|-------|-------|
| Phase status | planned / in_progress / blocked / completed |
| Owner | Name or team |
| Last updated | YYYY-MM-DD |
| In scope | One-line summary |
| Out of scope | One-line summary |

## Objective

1-3 bullets describing why this phase exists.

## Inputs / references

Explicit source docs required to execute this phase.

## Work items

| ID | Work item | Implemented | Verified | Evidence / notes |
|----|-----------|-------------|----------|------------------|
| Pn.1 | ... | - [ ] | - [ ] | ... |

## Blockers / risks

Current blockers with owner and next action.

## Exit criteria

Checklist required before phase status can be `completed`.

## Handoff

How to update `ROADMAP_MASTER.md` and which next phase to activate.
